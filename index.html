Export formats

Animated text HTML uses real selectable text with no canvas or video. Canvas HTML preserves every visual style. Plain text, text sequences, PNG, and WebM are also available from the Export window.

Browser support

HTML, text, and PNG export work in modern browsers. WebM recording depends on MediaRecorder support. Animated GIF decoding uses WebCodecs when available and a local fallback otherwise.
